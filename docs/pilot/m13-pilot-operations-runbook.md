# M13 Pilot Operations Runbook

This runbook is for the first controlled pilot. Keep notes short, factual, and tied to the Ad Work record.

## Daily Start

1. Confirm the pilot Ad Work is planned for the correct town, date, areas, package, and proof requirement.
2. Confirm the assigned driver and vehicle are approved and available.
3. Confirm the assignment is Ready for Execution.
4. Release the Ad Work and share the Work Code manually with the assigned driver.
5. Remind the driver to use foreground Phone Location Proof only after reading the consent screen and starting assigned work.

## During Work

- Watch execution status in admin.
- If the driver reports an issue, record the issue note and decide whether the work should continue.
- If photo proof upload fails, ask the driver to retry when network is stable.
- If Phone Location Proof has no recent update, call the driver and record the support action in admin notes.
- If the driver denies permission, continue the campaign only if AP accepts that Phone Location Proof may be unavailable.

## Offline Location Points

- Driver should use Sync Now after network returns.
- Admin should review Offline Points Synced and Last Update.
- If points remain pending after work ends, keep the Final Proof Summary in review until AP decides whether to close with a reason.

## Proof Review

1. Review uploaded proof photos.
2. Approve only photos that match the work area and proof note.
3. Reject or request more information for unclear proof.
4. Mark customer updates shared only after a person manually shares them.

## Location Proof Review

1. Review session status, first update, last update, points received, offline sync evidence, and warnings.
2. Use Needs Follow-up when permission, sync, or update timing needs clarification.
3. Keep technical coordinate values hidden unless an admin needs them for troubleshooting.
4. Do not share raw coordinates with customers.

## Customer Communication

- Use the approved customer communication text.
- Share only the customer-safe Final Proof Summary.
- Explain Phone Location Proof as supporting evidence reviewed by the team.
- Do not promise map playback, exact route proof, live driver watching, automatic messages, or distance-based billing.

## End Of Work

1. Confirm all planned days are completed or documented with an issue.
2. Confirm proof photos are reviewed.
3. Confirm customer updates are manually shared or accepted as not shared with a closure reason.
4. Confirm Location Proof Review is reviewed, not required, or documented as unavailable.
5. Prepare the Final Proof Summary.
6. Close the Ad Work or close with issues only when AP accepts the reason.

## Incident Handling

- Revoke driver access if a Work Code is shared with the wrong person.
- Stop Phone Location Proof if the campaign is cancelled or the driver should no longer submit proof.
- Do not delete proof or tracking records during an incident review.
- Record what happened, who was contacted, and the decision made.

## Pilot Completion

After the pilot, capture:

- number of enquiries tested,
- number of Ad Works completed,
- proof upload success or failure,
- Phone Location Proof status,
- support issues,
- customer wording feedback,
- AP decision for the next milestone.
