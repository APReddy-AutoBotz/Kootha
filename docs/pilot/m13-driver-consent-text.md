# M13 Driver Consent Text

Use this wording for the controlled pilot. Keep the same meaning if translating or reading it over a phone call.

## Short Notice

Phone Location Proof is used only as work proof for your assigned Prachar Ad Work. It starts only when you open your assigned work, read this notice, allow location permission, and choose Start Location Proof.

## What Is Collected

- phone location updates while assigned work is active,
- time of the first and last location update,
- offline sync status if the phone had poor network,
- photo proof and proof notes you submit.

## What Is Not Collected

- background location after work ends,
- location when you are not assigned to the Ad Work,
- location when you have not started Location Proof,
- customer-facing raw coordinates,
- microphone recording,
- camera capture by the app.

## Admin Review

Admin reviews the photo proof, proof notes, and Phone Location Proof status for assigned work. Customers do not get a live tracking link by default.

## When It Stops

Phone Location Proof stops when you take a break, end work, the admin stops it, the Work Code is revoked, or the Ad Work is closed.

## Driver Confirmation

I understand that Phone Location Proof is for assigned work proof only. I agree to use it during active assigned work when the admin requires it.
